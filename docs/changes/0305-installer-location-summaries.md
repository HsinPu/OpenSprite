# 安裝位置與解除安裝結果摘要

產品版本由 `0.21.20` 提升至 `0.21.21`；同步更新後端套件、uv 鎖檔與 README。

## 調整內容

- Windows 與 Linux 安裝完成時，列出程式、個人資料及自動啟動設定的實際位置，並說明設定、加密憑證、資料庫、工作區、技能、代理、封存、日誌、狀態及快取的相對位置。只顯示用途，不預先建立資料目錄或輸出檔案內容。
- Windows 下載入口在暫存清理完成後顯示已移除的路徑；沿用既有失敗診斷及無法清理時的保留提示。
- 解除安裝會比對操作前後是否存在，分別顯示已刪除、仍保留及原本不存在。Windows 保留既有結構化結果與確認／WhatIf 行為。
- Windows 使用 finally、Linux 使用 EXIT trap，在中途失敗時仍呈現剩餘狀態，保留原錯誤結果，並提醒殘留目錄可能已部分刪除。
- Linux 原本會把資料刪除失敗當成使用者取消而顯示保留資料；改成明確區分取消與刪除失敗，讓後者回傳失敗並顯示部分完成摘要。
- 預設仍保留個人資料；只有既有的明確資料移除選項與確認流程才會刪除。摘要列明不移除共用工具、工具快取、獨立原始碼或外部工作區。
- 主 README 加入兩個平台的資料位置表、子目錄用途及結果標籤說明。

## 驗證

- Windows 解除安裝測試通過：既有程序競態檢查，加上保留資料、移除資料、WhatIf、原本不存在及刪除失敗五種摘要情境；確認原結構化結果仍存在，錯誤不被摘要吞掉。
- Linux 以 WSL Ubuntu 非 root 測試帳號通過六項解除安裝測試，使用暫存 HOME／XDG 路徑及模擬 systemctl，涵蓋從安裝目錄內執行、自我移除、保留資料、終端機輸入 DELETE、取消確認、原本不存在、服務重載失敗，以及資料只刪除一部分時保留錯誤結果。
- Windows 完整安裝器隔離測試通過，包含前端建置、後端部署、啟動命令及下載入口等既有檢查。安裝與解除安裝摘要列出隔離目錄；測試原生套件仍出現既有 Windows 檔案鎖定提示，已保留並列出相關測試二進位檔案。
- WSL Ubuntu 完整 Linux 安裝器檢查通過，包含含空白路徑中的真實前端建置／後端部署及 systemd 服務檔驗證；沒有啟停或解除安裝真實使用者服務。建置保留既有大型 bundle 提醒。
- 安裝執行環境、Linux 安裝契約與資料路徑相關後端測試共 10 項通過。
- PowerShell 與 Bash 語法、版本一致性、離線鎖檔及 `git diff --check` 檢查通過。

測試只刪除自身建立的隔離檔案；沒有讀取真實憑證內容或刪除現有使用者資料。
