# 回應模式改用下拉選單並恢復預設

產品版本由 `0.21.18` 提升至 `0.21.19`；同步更新後端套件、uv 鎖檔與 README。

## 調整內容

- 預設模型的回應模式改用既有 Ant Design Select，沿用相鄰設定欄位的寬度、標籤與操作方式，移除小型 Radio 和其多欄樣式。
- 選項依序為「預設、低、中、高、極高、最高、極致」，英文為「Default、Low、Medium、High、Extra High、Max、Ultra」。排程也使用同一份選項清單。
- 選擇 `default` 時不送出思考等級參數，不送 `none`、`null` 或空的 reasoning 物件。模型採自身預設行為；這不代表強制關閉模型內部思考。
- 繁中提示為「不送出思考等級，使用模型預設行為。」；英文與既有日文介面同步補齊。明確選擇預設時，能力預覽不查詢供應商。
- 新安裝的初始偏好恢復為 `default`。已儲存的 `medium` 或其他等級保持原值，可由使用者自行改選預設。

## 儲存與相容性

既有 Run、資料庫限制及執行 adapter 已支援 `default` 的不指定行為；本次恢復設定／排程 API 的合法寫入值並同步契約與前端驗證，不需要新增資料庫欄位。AI 設定格式仍為 10，SQLite 格式仍為 19。

尚未升級的舊設定與第 18 版排程若選擇 `default`，升級時保留 `default`；其他舊等級仍依既有規則轉換。已由 0.21.18 轉成 `medium` 的設定不會被猜測性還原。歷史 Run 與事件不改寫。

- 相關後端測試 170 項、前端測試 98 項通過。

- 攔截 OpenAI、Anthropic、OpenRouter 的 HTTP payload，確認 `default` 不送推理等級參數，其他等級及最高支援等級回退維持正常。
- 驗證預設模式的 API 儲存／讀取、排程儲存／讀取、舊設定與排程升級、保留現有明確等級，以及預設預覽不查詢供應商。
- 前端驗證七個下拉選項、中英文提示、儲存成功、儲存失敗保留已確認選擇，以及載入前停用。
