# 自訂模型管理版面

## 調整

- 將供應商列內的模型清單與表單移至獨立 Ant Modal。
- 清單提供 NFC、不分大小寫的名稱／ID 搜尋、新增、編輯與確認移除。
- 新增與編輯切換為專用表單，取消不儲存，成功儲存返回清單。
- Context 與輸出容量桌面並排、窄畫面單欄，補上 tokens 與容量來源提示（三語）。
- 沿用既有人工模型儲存與重新探索保留機制，不改 API、壓縮政策或實際使用者設定。

## 驗證

- TypeScript typecheck 與 production build 通過；建置仍有大型 chunk 提示。
- CustomProviderCreate 與 useCustomProviders：7 項測試通過，涵蓋取消、搜尋、編輯大容量、儲存與移除確認。
- Vite 桌面瀏覽器確認獨立清單與編輯表單；沒有提交實際模型修改。
- 手機實機、完整前後端測試尚未執行。未更新本機安裝、版號或推送。
