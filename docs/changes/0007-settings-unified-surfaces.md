# 0007 - Settings unified surfaces

## Objective

將設定視窗內混用的背景色收斂為一致的白色，同時保留清楚的互動與狀態辨識。

## Changes

- 設定內容區、卡片、欄位、按鈕與控制元件統一使用全域白色 surface `--os-surface`。
- 左側分類導覽與手機版上方分類列維持白底，只有選中的分類使用全域淡橘色 `--os-primary-soft`，並以橘色文字標示目前位置。
- 分類 hover、選取項目與分段控制不再使用另一組淡橘底色，改以橘色文字、側線或底線表示狀態。
- 未開啟的切換控制改為白底與中性邊框；開啟狀態仍使用主色，避免失去開關辨識。
- 已連接標籤改為白底與綠色邊框，不再使用另一組淡綠背景色。
- 移除會覆蓋按鈕變體文字色的設定頁通用規則，並明確指定停用按鈕使用中性文字色。
- 設定頁的備用色碼與全域設計 token 對齊，避免脫離 App shell 時產生不同色盤。
- AI 模型頁整理為「模型廠家」與「選擇模型」兩張主要卡片，分開管理連線與模型偏好選擇。

## Public impact

只有設定視窗的視覺樣式改變。設定內容、互動、Demo 狀態與彈出視窗行為均不變。
